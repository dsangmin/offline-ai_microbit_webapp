      작은 손짓이 만드는 편안한 일상Chrome · micro:bit V1.5 ·

      손짓으로 시작하는 방법

      1. 먼저 타이머를 사용해 보세요.
        시간을 고르고 시작 버튼을 누르면 바로 사용할 수 있어요. ‘모델 없이 체험’은 손동작을 버튼으로 흉내 내는 기능이에요.
      2. 나만의 이미지 모델을 학습하세요.
        Teachable Machine의 이미지 프로젝트에서 ‘펼친 손’, ‘주먹’, ‘기타·손 없음’을 학습하세요. 배경만 있는 사진과 평소 작업 동작도 마지막 클래스에 포함하세요.
      3. 모델을 연결하고 동작을 지정하세요.
        모델 내보내기 → TensorFlow.js → 업로드한 모델의 공유 URL을 입력하세요. 클래스 이름이 다르면 ‘동작 연결’에서 시작·일시정지 클래스를 선택하세요.
      4. 카메라 또는 이미지로 시험하세요.
        카메라는 같은 결과가 설정 시간 동안 유지될 때 작동해요. 이미지 업로드는 분석 버튼을 누를 때 한 번만 판단해요.
      5. 마이크로비트를 연결하세요.
        MakeCode JavaScript 코드 다운로드 → MakeCode의 JavaScript 편집기에 붙여넣기 → 장치에 내려받기 → 다른 시리얼 창 닫기 → 이 페이지의 연결 버튼을 누르세요. 동작 클래스 이름도 코드와 맞춰 주세요.

      카메라·USB 연결은 데스크톱 Chrome의 HTTPS 또는 로컬 개발 서버에서 사용하세요. AI 라이브러리와 공유 모델을 처음 불러올 때는 인터넷이 필요해요. 실제 하드웨어 작동은 장치에서 별도로 확인해야 해요.
