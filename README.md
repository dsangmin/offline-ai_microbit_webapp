# 손대지 마! — AI 손동작 타이머

손이 젖거나 더러운 요리·미술·만들기 활동에서 **펼친 손으로 시작·재개, 주먹으로 일시정지**하는 타이머입니다. Teachable Machine 이미지 모델은 브라우저에서 추론하며, USB로 연결한 micro:bit V1.5에 상태를 표시합니다.

## 실행

런타임 패키지 설치나 빌드 없이 실행할 수 있습니다. 이 저장소에서:

```sh
python3 -m http.server 3000 --bind 0.0.0.0
```

자신의 컴퓨터에서는 Chrome으로 로컬 서버의 3000번 포트를 여세요. 배포할 때는 저장소를 Netlify 등의 정적 호스팅에 올리고 **빌드 명령 없이 게시 디렉터리를 `.`**로 지정하세요. 카메라와 Web Serial은 HTTPS 또는 localhost 같은 안전한 컨텍스트가 필요합니다. 파일을 더블 클릭하는 대신 웹 서버 사용을 권장합니다.

`index.html` 하나에 UI·CSS·웹앱 코드가 모두 들어 있습니다. 별도 백엔드, DB, API 키는 필요하지 않습니다. 타이머와 체험 기능은 AI 모델·카메라·micro:bit 없이도 작동합니다. AI 기능은 CDN 라이브러리와 공유 모델 다운로드를 위해 인터넷이 필요하므로 **완전한 오프라인 앱은 아닙니다**. 사진·영상은 서버에 업로드하지 않으며, 완료 기록 최근 30회와 시간·신뢰도 설정만 이 브라우저의 localStorage에 저장합니다. 열린 카메라·USB 연결과 진행 중인 타이머는 새로고침 후 복구하지 않습니다.

## AI 모델 학습 및 연결

1. [Teachable Machine](https://teachablemachine.withgoogle.com/train/image)에서 **이미지 프로젝트 → 표준 이미지 모델**을 만드세요. 소리·포즈 모델은 지원하지 않습니다.
2. 아래 세 클래스를 권장합니다. 클래스 이름은 자유롭게 지어도 되지만, 줄바꿈과 USB 상태 메시지용 `@timer:` 접두사는 사용할 수 없습니다.
   - `펼친 손`: 펼친 손바닥, 시작·재개용
   - `주먹`: 쥔 주먹, 일시정지용
   - `기타·손 없음`: 배경만 있는 화면, 평소 작업 동작, 두 동작 외 손 모양
3. 클래스별로 비슷한 양의 사진을 수집하세요. 다양한 거리·배경·조명·사용자를 포함하고, 학습에 쓰지 않은 사진으로 시험하세요. 같은 영상의 거의 동일한 프레임만 많이 모으면 실제 환경에서 인식이 어려울 수 있습니다.
4. 모델을 학습하고 **모델 내보내기 → TensorFlow.js → 모델 업로드**를 선택해 공유 URL을 복사하세요. 웹앱의 모델 URL 칸에 붙여넣고 불러오세요.
5. **동작 연결**에서 시작·재개 클래스와 일시정지 클래스를 선택하세요. 나머지 클래스는 타이머 동작에 연결되지 않습니다. 클래스 이름은 원문 그대로 표시·전송됩니다.
6. 기본 신뢰도 기준은 **80%**, 카메라 동작 유지 시간은 **1초**입니다. 같은 결과가 연속으로 유지될 때만 실행하며, 같은 클래스의 명령을 계속 반복하지 않습니다. 서로 다른 명령 사이에도 최소 1.5초의 간격을 둡니다. 신뢰도가 기준 미만이면 USB 명령을 보내지 않습니다.
7. 카메라 모드에서 카메라를 켜거나, 이미지 업로드 모드에서 JPG·PNG·WEBP를 선택하고 **이미지 한 번 분석**을 누르세요. 이미지 모드는 버튼을 누를 때 한 번만 판단합니다. 이미지 한도는 10MB·2,400만 화소입니다.

펼친 손을 계속 보여준 상태에서는 일시정지·완료 후 같은 명령이 자동 반복되지 않습니다. 다른 클래스를 충분히 보여 준 뒤 다시 펼친 손을 보여 주세요. 모델 없이 체험 버튼의 결과는 **모의 입력**이며 AI의 정확도를 검증하지 않습니다.

라이브러리는 Teachable Machine의 이미지 예제 조합인 TensorFlow.js `1.3.1`, `@teachablemachine/image` `0.8.5`를 고정하여 필요할 때 불러옵니다. 접근이 제한된 환경에서는 `cdn.jsdelivr.net`, `teachablemachine.withgoogle.com` 및 실제 모델·가중치가 저장된 호스트(예: `storage.googleapis.com`)에 대한 HTTPS 접근이 필요합니다.

## micro:bit V1.5 연결

1. [MakeCode](https://makecode.microbit.org/)에서 새 프로젝트를 열고 JavaScript 편집기로 전환하세요.
2. `microbit-makecode.js`의 전체 코드를 붙여넣으세요.
3. 클래스 이름이 권장 이름과 다르면 코드 상단의 `START_CLASS`, `PAUSE_CLASS`를 웹앱에서 선택한 클래스 이름과 **띄어쓰기·대소문자까지 같게** 수정하세요. 웹앱에서 동작 연결을 변경하면 보드 코드도 함께 맞춰야 합니다.
4. 코드를 micro:bit V1.5에 내려받으세요. **추가 부품·외부 전원은 필요하지 않습니다.** 기본 5×5 LED와 USB만 사용합니다. V1.5에 없는 내장 스피커·마이크는 사용하지 않습니다.
5. MakeCode의 장치 콘솔 등 다른 시리얼 연결을 닫으세요.
6. 데스크톱 Chrome에서 웹앱의 **마이크로비트 연결** 버튼을 눌러 장치의 시리얼 포트를 선택하세요.
7. **USB 전송 시험**에서 각 클래스 버튼을 눌러 표시를 확인하세요. 이 버튼은 보드 통신만 시험하며 웹 타이머를 조작하지 않습니다.

장치가 보이지 않으면 데이터 전송용 케이블인지 확인하고 OS의 장치 권한·micro:bit 펌웨어·다른 앱의 포트 사용 여부를 점검하세요. 브라우저에서 지원되지 않거나 USB가 끊겨도 웹 타이머는 계속 작동합니다. 연결 해제 버튼으로 포트를 닫을 수 있습니다.

### USB 프로토콜

- 속도: **115200bps**, 기본 8N1
- 인코딩: UTF-8
- 구분: 줄바꿈 `\n`
- AI 결과·수동 시험: 클래스 이름 원문. 예를 들어 `펼친 손\n`. 임의의 A/B 코드로 바꾸지 않습니다.
- 웹 타이머 상태: 클래스 이름과 별개인 예약 메시지 `@timer:ready\n`, `@timer:running\n`, `@timer:paused\n`, `@timer:finished\n`

AI 명령은 클래스 원문을 먼저 보내고 실제 웹 타이머 상태를 동기화합니다. 따라서 준비 중에 주먹을 보여도 실제 타이머가 멈춘 것으로 잘못 표시하지 않습니다. 수동 전송 시험은 클래스 한 줄만 보내므로 시험 중에는 보드 표시가 웹 타이머와 일시적으로 다를 수 있습니다. 수동 타이머 조작·다음 AI 명령·재연결 시 실제 상태를 동기화합니다.

| 상태 | micro:bit 표시 |
| --- | --- |
| 준비 | 작은 마름모 |
| 실행 | 재생 삼각형 |
| 일시정지 | 두 개의 세로 막대 |
| 완료 | 깜빡이는 체크 |

## 검증

자동 브라우저 검증용 개발 의존성은 다음과 같이 설치합니다. 앱 자체 실행에는 필요하지 않습니다.

```sh
npm ci --cache /tmp/touchless-npm-cache
npm test
```

테스트는 자체 로컬 서버를 열고 시스템 Chromium(기본 `/usr/bin/chromium`)을 사용합니다. 경로가 다르면 `CHROMIUM_PATH`로 지정하세요. 시스템 브라우저가 없다면 `npx playwright install chromium`으로 설치할 수 있습니다.

자동 검증의 AI 분류·USB 장치·카메라 입력은 테스트 대역으로 제어하여 경계 조건을 재현합니다. 이것은 **학습된 손동작 모델의 실제 인식 정확도나 하드웨어 검증을 대신하지 않습니다.**

```sh
npm run test:ai
```

추가로 실제 TensorFlow.js·Teachable Machine 이미지 라이브러리를 사용해 합성 모델의 로딩·이미지 추론·모델 교체를 검증할 수 있습니다. 이 검사는 인터넷과 `curl`이 필요합니다. 환경의 인증서 신뢰 설정을 사용하는 `curl`로 TLS 검증을 유지한 채 공식 CDN 파일을 받아 테스트 브라우저에 제공합니다. 합성 모델은 결과가 정해진 시험용 모델이므로 실제 손동작 분류 성능을 뜻하지 않습니다.

### 실제 장치에서 확인할 항목

- 5초로 설정하고 시작·일시정지·재개·초기화·완료를 확인하세요.
- 모델 연결 후 손바닥·주먹·손 없음에 대한 확률과 실제 명령을 확인하세요.
- 80% 미만 결과에는 명령이 없고, 같은 동작을 유지하면 반복 명령이 없는지 확인하세요.
- 다른 사람·배경·조명에서 오인식 횟수를 기록하세요. 카메라 영상에는 배경과 다른 손동작도 충분히 포함하세요.
- 이미지 업로드는 분석 버튼을 누르기 전에는 동작하지 않는지 확인하세요.
- 카메라를 끄거나 업로드 모드로 바꾸면 카메라 사용 표시가 꺼지는지 확인하세요.
- 각 수동 전송 버튼으로 보드의 클래스 처리와 LED를 확인하세요.
- USB를 뽑아도 타이머가 계속 진행되고 연결 상태가 갱신되는지 확인하세요.
- 완료 시 체크가 깜빡이고, 완료 기록이 한 번만 저장되는지 확인하세요.

수행평가에는 직접 확인한 시험 조건과 결과를 기록하세요. 실제 모델 URL과 물리 장치가 없는 상태에서는 AI 정확도·보드 작동을 검증 완료로 기재하지 마세요.
